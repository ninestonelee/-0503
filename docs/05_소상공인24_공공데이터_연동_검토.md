# 소상공인24 신규 공고 자동 수집 가능성 검토

- 검토일: 2026-10-13
- 결론: **소상공인24 자체의 공공데이터(오픈API·RSS)는 없음.** 대신 (1) 같은 생태계의 공식 오픈API 3종과 (2) 소상공인24 화면이 쓰는 내부 JSON API(비공식)를 조합하면 신규 공고를 자동으로 가져올 수 있음. 실제 호출로 검증한 결과를 아래에 정리.

## 2. 소상공인24 내부 API 사용법 (검증됨)

```
POST https://www.sbiz24.kr/api/pbanc/sbiz24PbancList
Content-Type: application/json
Accept: application/json
Referer: https://www.sbiz24.kr/
origin-method: GET        ← 이 헤더가 없으면 항상 500 INTERNAL_SERVER_ERROR

{
  "sortModel": [],
  "search": {
    "searchValue": "AI",                      // 키워드 (제목 검색, 동작 확인)
    "rcrtTypeCdNmList": [], "rcrtTypeCdNmListDisplay": "",
    "regionNmList": [], "regionNmListDisplay": "",   // 지역명 필터는 서버에서 적용되지 않음 (확인)
    "tpbizCdList": [], "tpbizCdListDisplay": "",
    "bhis": {"from": null, "to": null}, "wrkr": {"from": null, "to": null}, "sls": {"from": null, "to": null},
    "aplySeYn": "N", "sbrPbancYn": "N", "itrstPbancYn": "N",
    "departNmList": null, "searchBox": null,
    "departNmListDisplay": "소상공인시장진흥공단",    // 지방정부 공고: "자치단체" + "bizMngSeCd": "02"
    "ptPbancSortBy": null, "pbancNm": "", "regionCdList": []
  },
  "paging": true, "startRow": 0, "endRow": 10
}
```

응답: `data.default.total`(총 건수), `data.default.list[]`. 유용한 필드는 `pbancSn`(공고번호), `pbancNm`(공고명), `rcptPd.from/to`(접수기간), `bizPd`(사업기간), `rcrtTypeCd`(모집유형 코드, 101=소상공인, 102=전통시장, 113 등), `aplyPsbltySe`(Y=신청 가능), `ddlnDayCnt`(마감까지 일수), `bizMngSeCd`(02=자치단체). 상세 화면은 `https://www.sbiz24.kr/#/pbanc/{pbancSn}`.

주의: 이 API는 공개 문서가 없고 NetFunnel(대기열) 뒤에 있는 화면용 호출이라, 구조가 바뀌거나 차단될 수 있음. 하루 1~2회, 100건 단위 페이지 조회 정도로만 사용하고, 공식 경로(기업마당·K-Startup)를 1차 소스로 두는 것이 안전함. 사이트의 llms.txt(https://www.sbiz24.kr/llms.txt)도 "공고 내용은 사이트 최신 공고를 기준으로 안내"하라고만 명시하고 API를 언급하지 않음.

## 3. 권장 구성

1. **1차 소스(공식)**: 기업마당 API(인증키 1회 발급) + K-Startup API(공공데이터포털 키). 둘 다 무료.
2. **2차 소스(보완)**: 소상공인24 내부 API로 소진공·자치단체 공고를 하루 1회 수집해 1차 소스에 없는 공고만 추가.
3. **중복 제거·필터**: 공고명 기준 중복 제거, 키워드(AI·마케팅·판로·인건비)와 서울 소재 조건은 클라이언트에서 적용.
4. **알림**: 신규 공고만 캘린더 등록, 슬랙/이메일 발송. 이 세션에서 매월 1일 캘린더 체크 일정은 이미 등록되어 있으므로, 스크립트를 GitHub Actions cron(예: 매일 09:00 KST)으로 돌리면 월간 수동 확인을 대체할 수 있음.

## 4. 저장소에 추가한 PoC

- `scripts/fetch-notices.mjs`: 세 소스를 순서대로 호출해 `data/notices.json`에 스냅샷을 저장하고, 이전 실행 대비 신규 공고만 출력. Node 22 내장 fetch 사용, 의존성 없음.

```
# 키 없이: 소상공인24만 수집
node scripts/fetch-notices.mjs --region 서울 --keyword AI

# 키 설정 후: 세 소스 모두 수집
DATA_GO_KR_KEY=... BIZINFO_KEY=... node scripts/fetch-notices.mjs --region 서울
```

- 검증 실행(2026-10-13): 소상공인24 소진공 520건 + 자치단체 27건 수집 성공. K-Startup·기업마당은 키 미설정으로 건너뜀.
