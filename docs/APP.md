# 소상공인 지원사업 자가진단 — 실행 방법

Vite 5 + React 18 + TypeScript로 만든 단일 페이지 웹앱입니다.
소상공인이 받을 수 있는 정부 지원사업을 자가진단하고, 지원금 사용계획을 세우고, 신청 체크리스트와 공식 포털 링크를 한곳에서 관리합니다.

## 요구 사항

- Node.js 18 이상 (20 이상 권장)
- npm

## 실행

```bash
npm install      # 의존성 설치 (최초 1회)
npm run dev      # 개발 서버 실행 → 터미널에 표시되는 주소(기본 http://localhost:5173) 접속
npm run build    # 프로덕션 빌드 → dist/ 폴더 생성
npm run preview  # 빌드 결과 미리보기
```

## 구조

```
src/
  data/programs.ts       # 지원사업 규칙·프로그램·포털·팁·체크리스트 데이터 (정책 변경 시 이 파일만 수정)
  lib/eligibility.ts     # 자가진단 판정 로직
  components/
    Diagnosis.tsx        # 1. 자가진단
    BudgetPlanner.tsx    # 2. 지원금 사용계획 계산기
    Checklist.tsx        # 3. 신청 체크리스트 (localStorage 저장)
    Portals.tsx          # 4. 공고 링크 / 검색
  App.tsx, main.tsx, styles.css
```

## 기능 요약

1. **자가진단** — 사업자 유형·업력·지역·업종·상시근로자 수·연매출을 입력하면 추천 지원사업(예비창업/초기창업/청년창업사관학교/창업도약패키지/지자체·기업마당 사업/경영안정 바우처)을 보여줍니다. 유흥업·사행업은 지원 제외 안내, 업력 7년 초과는 "업력 리셋" 옵션을 안내합니다.
2. **지원금 사용계획 계산기** — 총 지원금(기본 4,000만원)을 항목별 비율로 배분하고, 지식재산권 0% 또는 홍보·마케팅 15% 미만이면 경고를 표시합니다.
3. **신청 체크리스트** — 체크 상태가 브라우저 localStorage에 저장됩니다.
4. **공고 링크/검색** — 소상공인24·기업마당·K-스타트업 링크와 빠른 검색 버튼을 제공합니다.
