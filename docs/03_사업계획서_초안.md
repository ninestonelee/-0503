# 사업계획서 초안: AI 기반 골반저근 스마트 코칭 솔루션 "휴케마 AI"

- 작성일: 2026-10-13 / 버전 0.1 (초안)
- 신청 기업: 리진바이오 주식회사 (서울 강서구)
- 용도: 혁신 소상공인 AI 활용지원(최대 4천만원), 초기·도약 창업패키지, 소상공인 도약 지원사업 등 공통 템플릿. 공고별 양식(PSST 등)에 맞춰 재배치해서 사용.
- 작성 원칙(영상 조언 반영): 전체 분량 10~20쪽, 처음부터 끝까지 "어떻게 돈을 벌 것인가". 현재(의자형 케겔운동기구 판매)가 아니라 미래(기기+앱+데이터 플랫폼)를 보여준다. AI 활용을 사업 정의에 포함한다.

> [확인 필요] 표시는 대표가 실제 수치로 채워야 하는 항목. 아래 숫자는 구조를 보여주기 위한 가정값이며 공고 제출 전 반드시 교체할 것.

## 1. 사업 개요 (1쪽)

**아이템 한 줄 정의**
TVR 미세진동 특허 기기(휴케마)에 AI 코칭 앱을 결합해, 요실금·골반저근 약화 사용자가 집에서 측정·운동·관리까지 한 번에 하는 **구독형 골반건강 스마트 코칭 솔루션**.

**핵심 변화**
| 구분 | 현재 (As-Is) | 목표 (To-Be, 24개월) |
|---|---|---|
| 제품 | 의자형 케겔운동기구 단품 판매·렌탈 | 기기 + AI 코칭 앱 + 월 구독 |
| 수익 | 1회성 기기 매출 | 기기 매출 + 구독 매출(반복) + B2B(산부인과·요양·피트니스) |
| 데이터 | 없음 | 사용 로그·강도·빈도 기반 개인화 프로그램 |
| 고객 접점 | 공식몰·블로그·전화 상담 | 앱 푸시·AI 상담봇·커뮤니티 |

**AI 활용 범위**
1. 사용 로그(진동 강도·세션 시간·빈도) 기반 개인별 운동 프로그램 자동 조정
2. 증상 설문 + 사용 데이터로 "이완 우선 / 강화 우선" 모드 추천 (블로그의 "골반저근 과긴장" 콘텐츠를 로직화)
3. 생성형 AI 상담봇: 제품 사용법·FAQ·후기 해석 자동 응답 (의학적 진단은 제외, 병원 진료 권고 가드레일)
4. 마케팅 자동화: 블로그·쇼츠 콘텐츠 초안 생성, 고객 리뷰 요약

## 2. 문제 인식 (Problem, 2쪽)

- 요실금은 성인 여성의 상당수가 경험하지만 병원 방문을 꺼리는 "숨은 수요"가 큼. [확인 필요: 국내 유병률 통계 출처 명기, 예: 대한배뇨장애요실금학회]
- 남성 전립선비대·야간뇨 고객도 늘고 있음(블로그 최근 글 반응). [확인 필요: 블로그 유입 통계]
- 기존 케겔운동기구는 "사면 끝". 꾸준히 하지 않으면 효과가 없는데, 지속 사용을 돕는 장치가 없음 → 재구매·추천이 약하고 렌탈 해지율이 높음. [확인 필요: 현재 렌탈 해지율·재구매율]
- 체험단 후기 위주 시장이라 신뢰 문제가 큼(블로그 "체험단 후기 믿어도 될까" 글). 데이터 기반 사용 기록이 차별점이 됨.

## 3. 실현 가능성 (Solution, 3~4쪽)

**제품 구성**
1. 하드웨어: 휴케마(기존) + BLE 모듈 추가 또는 앱 수동 입력(1단계는 수동 입력으로 개발비 절감) [확인 필요: 기기 통신 모듈 유무]
2. 앱(iOS/Android): 세션 기록, 주간 리포트, AI 프로그램 추천, 상담봇
3. 백엔드: 사용자 데이터, 추천 모델, 관리자 대시보드

**개발 로드맵 (지원금 집행 기간 기준 8~10개월)**
| 월 | 산출물 |
|---|---|
| 1~2 | 요구사항 정의, UX 설계, 상표·디자인권 출원 |
| 3~5 | 앱 MVP(수동 기록 + 규칙 기반 추천), 상담봇 베타 |
| 6~7 | 고객 50~100명 베타, 데이터 수집, 추천 로직 고도화 |
| 8~10 | 정식 출시, 구독 결제, 마케팅 집행, 성과 측정 |

**보유 역량**
- TVR 미세진동 특허(기술 진입장벽), 기존 고객 기반·공식몰·콘텐츠 채널(hukema.kr 일 1건 이상 발행 중)
- [확인 필요: 대표·팀 이력, 외주 개발사 또는 채용 계획]
