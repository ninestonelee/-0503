## 1. 한 줄 요약

## 3. 핵심 변경 사항(현재 → 바뀌는 것)

- **1. 메시지 일치**: "남자를 더 남자답게" 같은 범용 슬로건이었습니다 → 광고 주제(야간뇨·잔뇨감·약한 소변줄기·빈뇨·상담 소재, 기본값 포함 6종)와 롱폼·쇼츠 구분에 따라 헤드라인·서브카피·히어로 사진이 자동으로 바뀌고, 광고 영상의 장면·모델·색을 첫 화면에 이어 씁니다.
- **2. 첫 화면**: 정장 모델 사진과 슬로건뿐이었습니다 → 스크롤 없이 대상·해결하는 것·근거 1줄("듀얼모터 진동 · 자극점 3개 · 방석형")·구매/상담 버튼 2개가 모두 보이도록 위치를 고정합니다.
- **3. 공감**: "원인은 비대해진 전립선 때문"이라는 단정과 2017년 통계였습니다 → 생활 장면 카드 4개, 이름·연락처 없이 하는 1분 자가진단(결과 5구간별 다음 행동 안내)을 넣고, 통계는 최신 자료로 바꿉니다(못 바꾸면 "2017년까지의 자료" 표시).
- **4. 제품 설득력**: 근거를 알 수 없는 생리 효능 설명이었습니다 → 작동 원리 3단계 도식, 맨손 케겔·병원 진료와의 비방 없는 비교표, 사용법 3스텝, 핵심 반론을 다루는 FAQ 9개로 바꿉니다.
- **5. 신뢰**: 방송·인증 블록이 두 번 나오고 구버전 "3년 연속" 배지가 남아 있었습니다 → 수상·인증·등록·방송을 한 블록에 한 번만 싣고 항목마다 날짜·주최·증빙을 붙이며, 개발자 이해관계 안내와 후기 선정 기준을 공개합니다.
- **6. 구매 버튼**: 고정 버튼이 없고, 회원가입 쿠폰이 구매를 막고, 네이버 검색창으로 이탈했습니다 → 화면 아래 고정 구매·상담 바, 본문 버튼 3회 반복(첫 화면·중간·마지막), 가입 없이 결제 단계에서 2만원 자동 할인, 구매 버튼에서 주문서까지 최대 3번 누름으로 바꿉니다.
- **7. 상담**: 상담 기능이 없었습니다 → 3칸 신청 폼과 실시간 예약, 카카오 알림톡 확정·리마인드, 자가진단 결과 연동, 상담 고객 사은품, 응답 시간·노쇼 처리 기준을 만듭니다.
- **8. 로딩·사용성**: 본문이 글자가 박힌 이미지 30장(약 5.5MB)이었습니다 → 모든 문구를 텍스트로 바꾸고, 첫 화면 500KB·전체 2.5MB 이하·첫 화면 표시 2.5초 이하의 성능 예산과 섹션 12개·페이지 길이 상한을 정합니다.
- **9. 표현 안전성**: "확실한 효과 의사가 추천", "100% 리얼 후기", "세계최초", 다른 치료법 부작용 나열이 있었습니다 → 모두 삭제하거나 사실 기반 표현으로 바꿉니다(아래 6번 참고).
- **10. 측정·운영**: 종료된 구버전 구글 분석 도구(UA)가 남아 있고, 버튼 클릭 측정이 없고, 검색에 노출될 수 있었습니다 → 구버전 도구를 지우고 검색 제외 처리를 하며, 구매·상담을 나눠 측정하고 주간 리포트·A/B 테스트·점검표로 운영합니다.

## 4. 새 페이지 흐름(섹션 12개 + 고정 요소)

1. 히어로(광고별로 바뀜): 영상과 이어지는 첫인상, 대상·해결·근거와 구매/상담 버튼, 증빙으로 가는 배지 1줄입니다.
2. 공감·통계: 생활 장면 4개로 "흔한 일"임을 알리고, 출처·연도가 있는 통계를 보여 줍니다.
3. 1분 자가진단: 7문항으로 점검하고 결과에 따라 구매·상담·진료 권고로 이어 줍니다.
4. 원인·진료 신호: 원인을 단정하지 않고, 진료가 먼저 필요한 신호를 안내합니다.
5. 작동 원리: "앉는다 → 진동이 전해진다 → 골반저근 운동을 돕는다" 3단계와 근거 목록입니다.
6. 대안 비교: 맨손 케겔·병원 진료·V8을 비교하고 "진료를 대신하지 않습니다"를 밝힙니다.
7. 사용법 3스텝 + 중간 버튼: 설득 직후 가격·혜택·청약철회 안내와 구매/상담 버튼을 둡니다.
8. 신뢰 근거: 수상·인증·등록·방송·개발자 정보를 중복 없이 증빙과 함께 보여 줍니다.
9. 구매 후기: 구매 인증 후기 3개, 별점 분포, 선정 기준을 공개합니다.
10. 보건교육사 화상상담: 가치 제안, 상담사 소개(자격증 보기), 3칸 폼, 예약 시간 선택입니다.
11. FAQ 9개: 안전성·통증·체감 시기·주의 대상·소음/사생활·환불/AS·상담 후 구매 의무·비회원 구매·사용법을 다룹니다.
12. 마지막 버튼: 가격·보증 5줄을 다시 요약하고 회사 정보·약관을 싣습니다.

- 고정 요소: 첫 화면 버튼이 사라지면 화면 아래 구매·상담 바가 페이지 끝까지 보입니다. 구매 버튼은 옵션·수량·최종 금액을 확인하는 구매 창(화면 아래에서 올라옴)을 엽니다.

## 5. 전환 동선

**즉시구매**
1. 본문 또는 하단 고정 바의 구매 버튼을 누릅니다.
2. 구매 창에서 옵션·수량·최종 결제 예정 금액(할인 반영)과 배송·반품·A/S를 확인하고 "결제하기"를 누릅니다.
3. 상품 상세를 거치지 않고 쇼핑몰 주문서로 바로 갑니다. 비회원은 "비회원으로 바로 구매"를 고릅니다(여기까지 최대 3번 누름).
4. 카드 또는 주문서의 네이버페이·카카오페이로 결제하면 주문이 완료됩니다.
- 주문서 바로 연결이 안 되면 상품 상세의 구매 창이 같은 옵션·수량으로 열리는 대체 경로(최대 4번 누름)를 씁니다.

**보건교육사 화상상담**
1. 상담 버튼(고정 바·본문·자가진단 결과)을 누르면 상담 신청 영역으로 이동합니다.
2. 부르실 이름(실명 아니어도 됨)·휴대폰 번호·희망 일시(오늘부터 7일)를 넣고 필수 동의 2개에 체크해 신청합니다. 자가진단 결과는 동의할 때만 함께 보냅니다.
3. 화면에 예약 완료 카드가 뜨고, 1분 안에 카카오 알림톡으로 확정과 입장 링크가 옵니다. 상담 30분 전(조건에 따라 전날 저녁 8시도) 다시 알려 드립니다.
4. 앱 설치 없이 링크로 20분 상담을 받습니다(카메라 꺼도 됨, 녹화·녹음 없음, 구매 권유 없음). 상담 후 2시간 안에 요약 알림톡을 보냅니다.
5. 광고 수신에 동의한 분께만 상담 고객 전용 혜택(할인가 + 사은품, 상담일로부터 7일 이내 주문) 구매 링크 문자를 보냅니다.

## 7. 성과 목표와 측정

> 아래 목표치는 모두 **가정**입니다. 현재 페이지에는 버튼 클릭 측정이 없어 기준값이 없으므로, 출시 전 최근 28일 값을 채우고 출시 4주 차 리뷰에서 실제 값으로 다시 정합니다.

| KPI | 목표(가정) |
|---|---|
| 이탈률 | 50% 이하 |
| CTA 클릭률(전체 / 구매) | 20% 이상 / 12% 이상 |
| 상담 신청률 | 2.5% 이상 |
| 구매 전환율 | 1.2% 이상 |
| 상담→구매율(상담 후 14일 안 구매) | 20% 이상 |
| 자가진단 시작률 / 완료율 | 25% 이상 / 70% 이상 |
| 상담 참석률 | 80% 이상(노쇼 20% 이하) |
| 첫 화면 주요 콘텐츠 표시 시간(LCP, 모바일) | 2.5초 이하 |

- 구글 애널리틱스 4(GA4)로 스크롤·섹션 노출·구매/상담 버튼 클릭·자가진단·상담 신청·구매를 따로 기록하고, 구글 광고에서는 "구매"와 "상담 신청"을 기본 전환으로 잡습니다.
- A/B 테스트(두 안을 나눠 보여 주고 비교하는 실험) 4종을 한 번에 하나씩 진행합니다: 헤드라인 문장 → 자가진단 위치 → 고정 바 버튼 크기 → 가격 표기(최소 14일, 필요 표본을 채울 때 판정).
- 매주 월요일 주간 리포트(KPI·소재별 성과·단계별 이탈·상담 운영·A/B 현황·변경 사항)를 작성합니다.
