## 3. 핵심 변경 사항(현재 → 바뀌는 것)

- **1. 메시지 일치**: "요실금 — 자신의 의지와 무관하게 소변이 새는 증상"이라는 질병 정의 문구였습니다 → 광고 주제(기침·재채기 / 웃음·운동 / 절박뇨·빈뇨 / 출산 후 / 갱년기 / 케겔이 어려움 / 무료 상담, 7종 + 기본값)에 따라 헤드라인·서브카피·히어로 사진이 자동으로 바뀌고(롱폼·쇼츠에 따라서는 서브카피 길이·맨 위 안내 문구·사진 비율이 바뀜), 광고 영상의 모델·의상·공간·색과 엔드카드 문구(= 헤드라인)를 첫 화면에 이어 씁니다.
- **2. 첫 화면**: 배를 움켜쥔 여성 사진과 원인 단정 문구만 있고 구매·상담 버튼이 없었습니다 → 주소창이 보이는 작은 화면에서도 스크롤 없이 '여성용' 대상 표시, 25자 이내 헤드라인(기본 "기침·웃음에 새는 소변, 앉아서 운동해요"), 근거 1줄(증빙이 그대로 뒷받침하는 특허·자극점 문장 하나), 신뢰 배지 1줄(KC 인증 · 2022~2025 한국품질만족도 4년 연속 1위), 광고 혜택 줄("20,000원 할인 · 무료 화상상담", 할인 B안이면 "가입 시 20,000원 할인 · 무료 화상상담"), 구매·상담 버튼 2개가 모두 보이게 합니다.
- **3. 공감**: 연도 없는 통계와 "수직상승", 체크 3개 뒤 "모두 다 요실금에 해당합니다", "방치하면 중증으로 발전" 같은 단정·공포 표현이었습니다 → 생활 장면 6개와 "많은 여성이 겪는 일" 정상화 문장, 이름·연락처를 묻지 않는 8문항 1분 자가진단(결과 4구간 + 진료 권유), 출처·연도가 있는 통계(심평원 최신 연도 복압성 요실금 여성 환자 수는 항상 표시)로 바꾸고, 그냥 두었을 때의 생활 불편은 관리를 시작하는 방법과 함께 전합니다.
- **4. 제품 설득력**: "음핵 내 8,000개 신경세포 활성화" 같은 근거 미상의 효능 주장과 "불수의근이라 혼자 하면 실패" 같은 오정보였습니다 → 작동 원리 3단계 도식, 자사 제품 간 자극점 비교(1곳 → 3곳), 혼자 하는 케겔·병원 치료·다른 케겔 기구와의 비방 없는 비교표, 사용법 3스텝, 핵심 반론을 다루는 FAQ 10개로 바꿉니다. 질압 측정 자료는 보고서 원본(측정 주체·측정일·방법)·단위 확인과 광고심의를 모두 통과할 때만 평균 범위로 싣습니다.
- **5. 신뢰**: 방송·인증 블록이 두 번 나오고 구버전 "3년 연속" 배지가 2곳에 남아 있으며, 의료인 3명의 추천 블록과 "100% 리얼 후기"가 있었습니다 → 수상·KC·특허·디자인/상표·방송을 한 목록에 한 번만 싣고 항목마다 날짜·주최(발급)·증빙을 붙이며, 의료인 블록은 지우고 개발자·공동개발자의 이해관계를 밝힙니다. 후기는 구매 확인 후기만 싣고 별점 분포·노출 기준·제외 건수를 공개합니다.
- **6. 구매 버튼**: 고정 버튼이 없고, 회원가입 쿠폰이 구매를 막고, 네이버 검색창으로 이탈했습니다 → 화면 아래 고정 구매·상담 바, 본문 버튼 반복(첫 화면·중간·마지막·자가진단 결과), 회원가입 없이 바로 구매, 상품 상세 화면을 거치지 않는 주문서 연결(회원 2번·비회원 3번 누름, 옵션이 있으면 +1번)로 바꿉니다. 2만원 할인은 할인 A안(비회원 포함 기간할인)이면 비회원까지 주문서에서 자동으로 빠지고, 할인 B안(간편가입 쿠폰)이면 회원가입 때 자동 발급되는 2만원 쿠폰이 주문서에서 자동 적용되고(로그인 화면에서 카카오 간편가입을 맨 위에 안내), 비회원은 할인 없이 구매합니다(정하지 않으면 A안. A안 설정에서 비회원을 고를 수 없으면 판매가를 할인가로 바꿔 같은 결과를 냅니다).

- **8. 로딩·사용성**: 본문이 글자가 박힌 이미지 34장(약 12MB, JPG·GIF)이었습니다 → 모든 문구를 텍스트로 바꾸고, 첫 화면 500KB·전체 2.5MB 이하·첫 화면 표시 2.5초 이하의 성능 예산(넘으면 배포하지 않음)과 섹션 12개·페이지 길이 상한(현재보다 짧게)을 정합니다.

3. 1분 자가진단: 8문항으로 점검하고 결과(4구간 + 진료 권유)에 따라 구매·상담·진료 권유로 이어 줍니다.
4. 원인·유형·관리 시작: 골반저근 설명, 복압성·절박성·혼합성 유형, 진료가 먼저인 신호, 그냥 두었을 때의 생활 영향과 관리 시작 방법입니다.
5. 작동 원리: "앉아요 → 진동이 전해져요 → 골반저근 운동을 도와요" 3단계, 특허 근거 줄, 자극점 1곳 → 3곳 비교입니다.
6. 방법 비교: 혼자 하는 케겔·병원 치료·다른 케겔 기구와 비교하고 "진료를 대신하지 않아요"를 밝힙니다.

10. 보건교육사 화상상담: 가치 제안 5개, 상담사 소개(자격·소속·역할), 물어볼 수 있는 것·하지 않는 것, 예약 버튼입니다(예약 화면을 불러오지 못하면 전화 예약 안내로 바뀜).

## 5. 전환 동선

**즉시구매**
1. 본문 또는 하단 고정 바의 구매 버튼을 누릅니다(버튼 이름: 할인 A안 "할인가로 구매하기"(고정 바 "할인가로 바로 구매"), 할인 B안 "가입하고 할인 구매"(첫 화면·고정 바)·"간편가입하고 할인가로 구매"(중간·마지막·자가진단 결과)).
2. 옵션이 없으면 상품 상세 화면 대신 "주문서로 이동하고 있어요" 안내가 잠시 뜬 뒤 다음 화면으로 넘어갑니다. 옵션이 있으면 랜딩 안 구매 창에서 옵션·수량·결제 예정 금액(2만원 할인 반영)과 7일 청약철회를 확인하고 "주문서로 이동"을 누릅니다(B안이면 가입 시 금액과 비회원 금액을 함께 표시).
3. 로그인한 고객은 바로 주문서로 갑니다. 비로그인 고객의 로그인 화면은 A안이면 "비회원으로 바로 구매"가 맨 위, B안이면 "카카오 간편가입하고 20,000원 할인"이 맨 위이고 그 아래 "비회원으로 바로 구매"(쿠폰 할인 미적용 고지)가 보입니다.
4. 주문서에는 A안이면 할인가가 자동 반영되고, B안이면 가입 회원에게 2만원 쿠폰이 자동 적용됩니다(실패하면 "쿠폰 적용하기" 안내). 결제하면 주문이 완료됩니다(결제수단은 카카오페이·네이버페이·토스페이 가운데 계약된 간편결제 → 신용카드 → 무통장입금 순).
- 누르는 횟수(결제 정보 입력 제외)는 회원 2번, 비회원 3번(옵션이 있으면 +1번)이고, 다음 화면이 뜰 때까지 2.5초 이하가 목표입니다. 자동 연결이 3초 안에 시작되지 않으면 일반 상품 상세 화면으로 돌아가 "옵션을 고른 뒤 아래 구매하기를 눌러 주세요"라고 안내하고, 로그인 화면·주문서에서 뒤로 가기를 누르면 일반 상세 화면을 거쳐 랜딩으로(브라우저에 따라 한 번에 랜딩으로) 돌아옵니다(로딩 화면에 갇히거나 주문서로 다시 튕기지 않음, v12).

- 수상·방송·인물 정보(마케팅·지식재산 담당·경영지원, D-7): 한국품질만족도 수상은 주최·수상일 중 하나라도 확인되지 않으면 히어로 배지를 'KC 인증'만 남기고 수상 행을 숨깁니다. 2021 소비자만족도는 주최·수상일 중 하나라도, 디자인·상표는 번호·등록일 중 하나라도 없으면 숨깁니다. 방송은 방영일·협찬 여부가 확인되지 않은 회차만 숨기고(영상 사용 허락이 없으면 캡처만), 장성해 인터뷰는 회차·방영일·협찬 여부가 확인되지 않으면 방송 언급을 지웁니다. 장성해(소속·관계)·김오곤 원장(공동개발 관계·노출 동의) 자료가 없으면 해당 인물 줄을 지우되 "의료인의 추천·보증이 없다"는 공통 고지는 남깁니다.
- 특허 청구항의 자극점 3곳 구조(품질·지식재산 담당, D-14)·자극점 비교 도면(개발, D-7): 결과에 따라 마케팅 책임자가 D-7에 히어로 근거 1줄을 정합니다(청구항 확인 → "특허 진동파장이 PC·BC 근육 3곳을 자극", 아니고 도면 있음 → "자극점 1→3곳(PC·BC 근육, 자사 제품 비교)", 둘 다 없음 → "특허 「진동파장을 통한 여성 질 수축 장치」"). 질압 측정 보고서(개발·품질, D-7)가 없으면 측정 자료 카드를 싣지 않습니다.
- 상담 고객 혜택(별도 혜택: 마케팅 / 사은품 품목·재고: 마케팅·물류, 모두 D-7): 별도 혜택이 없으면 사은품으로, 사은품도 없으면 혜택 없는 구매 링크 안내를 1회 보내고 동의 문구를 "상담 후 제품 구매 안내 받기"로 바꿉니다. 알림톡 발신 프로필(운영, D-14)이 없으면 모든 안내를 문자로 보내고 화면 문구도 '문자로'로 바뀝니다. 080 무료 수신거부 번호(운영, D-14)가 없으면 광고 문자 대체 발송을 끄고, 카카오 친구톡을 받지 못한 분께는 상담 고객 메시지를 보내지 않습니다(상담 중 채팅 구매 링크만 운영).
- 상담 인력·운영 시간(상담팀장, D-10): 확정되지 않거나 연장 시간에 전화 착신 전환이 안 되면 화·목 저녁 연장 없이 평일 10~18시로 운영합니다.
- 후기 데이터(CS·마케팅, D-7): '구매 고객만 작성' 설정이 꺼져 있으면 D-7에 켜고 그날 이후 후기만 씁니다. 후기 적립금 운영 여부를 확인하지 못하거나 집계 대상 후기가 0건이면 후기 섹션을 싣지 않습니다.
- 기존 통계 발표 연도(마케팅, D-7)가 없으면 55.7%·71% 통계를 빼고 심평원 통계만 씁니다. 무이자 할부(재무·PG 담당, D-7)가 없으면 할부 줄을 숨깁니다.
